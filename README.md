A bold, raw, and unapologetically Gen Z streetwear brand website that breaks all the rules and sets new ones.

## 🔥 Features

### **Bold Design Elements**
- **Dark Mode First**: Pure black (#0a0a0a) background with neon green (#00ff41) accents
- **Raw Typography**: Oswald for headings, Inter for body text
- **Glitch Effects**: Hover animations with glitch aesthetics
- **Neon Glow**: Text shadows and glowing elements
- **Street Art Vibes**: Graffiti-inspired visual elements

### **Modern User Experience**
- **Responsive Design**: Mobile-first approach with hamburger navigation
- **Smooth Scrolling**: Seamless navigation between sections
- **Animated Elements**: Floating emojis and scroll-triggered animations
- **Interactive Product Cards**: Hover effects and quick view modals
- **Form Validation**: Modern contact form with real-time feedback

### **Gen Z Appeal**
- **Bold Messaging**: "STREET REVOLUTION", "WE ARE THE REBELLION"
- **Raw Language**: Authentic street terminology and edgy copy
- **Social Media Ready**: Instagram, TikTok, YouTube integration
- **Mobile Optimized**: Perfect for Gen Z's mobile-first lifestyle
- **Visual Storytelling**: Emojis and visual elements that speak to youth culture

## 🚀 Getting Started

1. **Clone or Download** the repository
2. **Open in Browser**: Simply open `index.html` in any modern browser
3. **Local Server** (recommended):
   ```bash
   cd /workspace
   python3 -m http.server 8000
   # Visit http://localhost:8000
   ```
